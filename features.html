NEW / WORKING AI & IT UTILITIES

Four tools. One delivery workflow.

Inspect agent capabilities, ground retrieval in evidence, review interface changes, then explore failure recovery. These browser-side utilities run without API keys, paid models or backend uploads.

01 / TRUST

MCP Trust Lab

Review MCP configurations and tool manifests for risky launch commands, credential literals and broad capabilities. Export an actionable human-review checklist. Static heuristics—not a security certification.

Inspect MCP configuration →Repository & tests
02 / EVIDENCE

RAG Evidence Lab

Compare document chunking strategies, run a transparent BM25 lexical baseline, inspect exact citation ranges and export retrieval evidence. No embeddings or LLM inference are implied.

Compare retrieval evidence →Repository & tests
03 / CONTRACTS

API Contract Lens

Compare OpenAPI 3.0/3.1 JSON contracts for removed endpoints, tighter requests and weaker response guarantees. Export a migration checklist before changing consumers.

Review an API migration →Repository & tests
04 / RESILIENCE

Retry Lab

Simulate capped exponential backoff, jitter, request deadlines and circuit breakers. Compare seeded outcomes, request amplification and hypothetical costs without calling a real service.

Explore retry trade-offs →Repository & tests
